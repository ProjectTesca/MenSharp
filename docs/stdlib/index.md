# 標準ライブラリ

M# 専用の標準ライブラリがあります。

!!! warning

    完全に網羅しているわけではありません。対応している記法は、ここにあるもの以外にもあります。

- [HTTP](http.md) — `MenSharp.Net.Http` と async/await
- [JSON](json.md) — `MenSharp.Json`
- [`Result<T, E>` と `Option<T>`](result.md)
- [静的リフレクション](reflection.md) — `MenSharp.Reflection`

C# 側の async/await、コレクション、Behaviour は [言語機能](../language/index.md) を参照してください。
