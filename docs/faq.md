# Q&A

??? question "サポートされているプラットフォームは？"

    Udon Assembly にコンパイルされるので、VRChat の対応プラットフォームと同じです。ただし、コンパイラ本体は Windows、macOS（Apple Silicon）、Linux のみサポートされます。

??? question "ライセンスは？"

    コンパイラのソースは MIT ライセンスです。**M# を使用してコンパイルした結果の Udon Assembly にはライセンスは付与されません。** ご自由に使用してください。
